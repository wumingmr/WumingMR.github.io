旧手机不要扔，装个 Termux 变身 7x24 小时服务器

开头引入

家里躺着一台退役的旧手机，屏幕碎了懒得修，卖二手又不值钱。其实，它完全可以变废为宝——当作一台 7x24 小时运行的 Linux 服务器。Termux 是 Android 上的终端模拟器，能提供完整的 Linux 环境，配合 SSH、Nginx、Python 等工具，足以支撑博客、定时脚本、下载任务、内网穿透等轻量服务。本文不聊理论，直接上实操，带你从零开始完成部署，并处理掉最常见的几个坑（比如 Termux 被系统杀后台的问题）。

为什么要用手机当服务器

手机当服务器的核心优势是低成本。你不需要额外购置树莓派或云主机，一块旧电池加上 Wi-Fi 就能跑起来。性能方面，如今千元机的 CPU 和内存其实远超十年前的 PC，跑 Nginx 和 Python 脚本绰绰有余。缺点是持久性和稳定性不如专业服务器，但通过下文介绍的 Termux 保活技巧，可以实现连续运行数周不宕机。

对于个人项目来说，用手机做服务器还有一个好处：数据完全掌握在自己手里。不用担心云服务商跑路或审查，也不用为 1 核 2G 的小主机每年支付几百元。接下来，我们直接进入部署环节。

总结

到此，一台旧手机已经成功变成了一台能对外提供服务的轻量服务器。我们完成了 Termux 的安装与源配置、SSH 远程管理、Nginx/Python 服务部署、以及通过内网穿透实现公网访问。整个过程不依赖任何付费工具，也不需要对手机进行 root。

想进一步加固稳定性，建议开启 Termux 的 termux-services 来管理脚本的自动重启，在 ~/.bashrc 中添加启动命令，并给手机设置一个固定 Wi-Fi 和充电周期，防止电池耗尽导致服务中断。也可以考虑安装 rsync 做定时备份，避免存储损坏丢失数据。
