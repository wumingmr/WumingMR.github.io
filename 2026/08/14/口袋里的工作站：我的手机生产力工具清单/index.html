口袋里的工作站：我的手机生产力工具清单

手机常被当成”消费设备”，刷视频、回消息、拍照。但当我开始认真用它干活，发现一台 Android 手机加一双手，几乎能覆盖我日常工作流的八成。这篇文章是我长期筛选后留下的生产力工具清单，不求大而全，只讲真正每天都在用的东西。

输入：一切效率的起点

手机生产力的瓶颈从来不是性能，而是输入。我花了不少冤枉钱买键盘，最后留下的方案很朴素：蓝牙机械键盘 + 输入法自定义词库。

键盘选的是矮轴 60% 配列，够轻够小，放进包里没有存在感；配合 Termux 里的 vim 写文档、写脚本，效率跟台式机没有本质区别。输入法方面，我深度使用了自定义符号短语，把高频片段（邮箱、命令前缀、常用地址）做成快捷键，省掉大量重复输入。

另一个容易被忽略的输入工具是剪贴板管理器。手机上复制一段话再切到别处粘贴，来回切换的成本很高。装上剪贴板历史工具后，复制过的内容随时可查，长文本拼接也变成复制粘贴两下的事。

终端：把手机变成工作站

如果说输入是入口，Termux 就是整个生产力体系的发动机。我在 Termux 里装了三样东西，几乎能处理所有日常事务：

  • 终端复用与编辑器：tmux + vim，多会话保持、远程断线不丢任务；
  • 语言与脚本环境：Python 和 Node.js，写自动化脚本、处理数据都靠它们；
  • 包管理：pkg 一键安装，需要什么工具随时补上。

配合 Shizuku 授权，还能在终端里执行一些系统级操作，比如批量管理文件、调用系统 API，把”手机管手机”变成了现实。键盘、终端、脚本三件套齐了之后，手机就不再是娱乐设备，而是一台随身 Linux 小主机。

自动化：让重复的事自己跑

工具清单里最值钱的一项，是自动化。我手机上的自动化脚本分两类：一类挂在系统定时任务里，比如每天固定时间备份照片、整理下载目录；另一类是”触发式”的，比如收到特定通知就执行对应动作，或者连上家里 Wi-Fi 自动切换工作模式。

写自动化有个经验：先从最痛的点开始。别一上来就设计宏大的自动化体系，挑一个每周都会做、且机械重复的操作，花半小时写成脚本，立刻就有正反馈。跑顺一个，再扩展到下一个。半年下来，你会发现手机帮你省掉的时间远超想象。

数据这块我坚持 3-2-1 备份原则：重要文件本地一份、外置一份、云端一份。自动化脚本本身放在 git 仓库里，改坏了随时回滚，重装系统一键拉回。

记录：知识不落地等于没记

生产力不止是”做”，还包括”记得”。我用 Markdown 建了一个个人知识库，所有笔记、灵感、踩坑记录都按主题归档，配合全文搜索，查找几乎零成本。

这里的关键是降低记录门槛：想到什么随手记，不追求格式完美，先存下来再说。每周花十分钟整理一次，把零散条目合并、打标签。坚持下来，这个知识库会变成你最有价值的数字资产，比任何付费笔记软件都靠谱。

小结

这份清单没有一样东西是昂贵的，核心就三句话：把输入配好，把终端用好，把重复的事自动化。工具永远在迭代，但方法论是稳定的——手机生产力的本质，是让随手可得的设备承担起原本需要专门工具才能完成的工作。
