断网、息屏、切后台都不怕：tmux 让终端会话真正持久

写作注释: 本文由 AI 生成, 主题「tmux 入门: 断线不丢的终端会话」, 内容仅供参考, 欢迎留言交流。

用 nohup 把任务丢到后台，是终端新手最常抄的作业。但它有个致命前提：进程必须活着。一旦手机息屏被系统回收、Termux 被切到后台后进程被杀，或者你只是随手关掉了终端窗口，那条命令就跟着消失了。

tmux 解决的正是这个问题。它把「跑着的进程」和「看它的那个终端窗口」拆成两件独立的事：窗口可以随便关，进程活在 tmux 服务器里；下次重新连上，界面原样恢复。

一、先理解它的三层模型

tmux 的结构是嵌套的，这一点想通了，后面所有命令都是自然结果：

  • server：真正跑进程的地方。你关掉所有终端窗口，server 依然在后台。
  • session：工作的组织单位，可以同时开多个，互不干扰。
  • window / pane：纯粹是「怎么看」，切分、切换都不会影响任何进程。

记住一句话：窗口是视图，进程在 server 里。这就是持久化的全部秘密。

二、前缀键：所有操作的入口

tmux 绝大多数操作都挂在前缀键后面，默认是 Ctrl-b。也就是说，你按下的其实是两个键的组合：Ctrl-b，松开，再按第二个键。这个「松开再按」的习惯是上手时最容易卡住的地方——很多新手以为要按住不放，结果发现毫无反应。

几个最该先记住的：

按键 作用
Ctrl-b d detach，脱离会话但进程继续跑（最常用）
Ctrl-b s 列出所有会话并切换
Ctrl-b c 新建窗口
Ctrl-b n / p 切换到下一个 / 上一个窗口
Ctrl-b % 垂直切分（左右）
Ctrl-b " 水平切分（上下）
Ctrl-b 方向键 在窗格间移动
Ctrl-b z 把当前窗格全屏放大，再按一次还原
Ctrl-b [ 进入复制模式，可翻页、回溯滚动的输出

最后一条是被严重低估的功能。很多时候程序报错刷屏，日志已经滚到几千行之前了。进入复制模式后可以用方向键和 PageUp 往回翻，找到那段输出后按 q 退出，而不需要重新跑一遍程序。很多人不知道 tmux 能回溯滚动历史，用了几年才发现，绕了很大的弯路。

四、手机上（Termux）的实际情况

桌面上的 tmux 教程不会告诉你这些坑：

  1. 务必装 Termux:Boot 和 Termux:Tasker，并且在电池优化里把 Termux 排除掉。这是 session 能活过息屏的唯一前提。tmux 只是让进程脱离终端窗口存活，它不能对抗 Android 系统的杀进程策略——两者要配合使用。
  2. 从通知栏重新进入 Termux 后要 tmux attach，不会自动接回上次的会话。养成习惯：进去第一件事就是 tmux a -t 名字。
  3. tmux 的 socket 目录默认在 $PREFIX/var/run，多个 Termux 用户的 UID 不同时要留意权限。可以用 tmux -L socket名 指定独立的 socket，避免多用户互相串会话。
  4. 剪贴板需要额外配置。tmux 自带的复制模式缓冲区不等于系统剪贴板，跨应用粘贴要装 termux-clipboard-get / termux-clipboard-set 并在配置里绑定。这个功能比较折腾，实用度因人而异。

一个实用的日常模式是：长任务（编译、下载、跑批处理）一律在 tmux 里跑，跑完 Ctrl-b d 脱离，剩下的时间随便用。回到 Termux 时 tmux a 回来，进度条还在那里跑。

常见问题

会话还在但界面很怪（乱码、宽度不对）
多半是客户端和服务器的终端类型不一致。在配置里加上 set -g default-terminal "tmux-256color"，然后 detach 重新 attach。

tmux attach 报 already running
说明你已经在一个 tmux 里了。直接 Ctrl-b s 切换会话，或者先 Ctrl-b d 出来。

找不到某次 detach 之前的窗口
用 Ctrl-b s 看全部会话。tmux 从不主动删除会话，除非你手动 kill-session，所以东西一般都在。

总结

tmux 的价值不在「多标签页」——那点它不如 GUI 终端。它真正的价值是把会话寿命和终端窗口寿命解耦，让你敢于随手关窗口、敢于让手机息屏。

建议的使用顺序：

  1. 装好 Termux:Boot + 排除电池优化（前提）
  2. 习惯 Ctrl-b d 而不是直接关窗口
  3. 学会 Ctrl-b [ 回溯滚动（收益最大，也最被忽视）
  4. 配上 ~/.tmux.conf 里的鼠标和颜色支持

前三步做完，你就已经能覆盖 90% 的使用场景了。
